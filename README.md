<details>
<summary><b>⚙️ One-time setup for the snake animation (click to expand)</b></summary>
<br/>

This one won't render until you enable it — it's generated by a GitHub Action in your own profile repo (`adityaarora-dev/adityaarora-dev`), not a public API link.

1. In that repo, go to **Actions → New workflow → set up a workflow yourself**
2. Paste this as `.github/workflows/snake.yml`:

```yaml
name: generate contribution snake
on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch: {}
  push:
    branches: [ main ]

jobs:
  generate:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: Platane/snk@v3
        id: snake-gif
        with:
          github_user_name: adityaarora-dev
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark
      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

3. Commit it, then run it once manually from the **Actions** tab (`Run workflow`)
4. It'll push the SVGs to an `output` branch — after that, the embeds above light up automatically and refresh daily
</details>
